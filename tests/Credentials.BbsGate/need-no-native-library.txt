# The tests of bbs-2023 test classes that need no native library, each with the reason.
#
# A bbs-2023 test class is a type declared in a test source file whose code names anything of bbs-2023.
# The no-library gate (tools/check-bbs-tests-without-library.sh) runs every test again with NetCrypto's
# native BBS library removed. A test of such a class has to FAIL there, unless it is named here; a test
# named here has to PASS there. So an entry is checked by running, and a wrong one fails the gate.
#
#   <namespace>.<class>.<method> | <reason>
#
# One test a line (all the rows of a theory at once), so that a new test of a bbs-2023 class is never
# covered by an entry that was written before it. The gate checks that an entry passes without the
# library; that the test is worth having there is for whoever reviews the entry.
#
